# agy-me 功能与运维说明

## 页面

仪表盘 · 账号 · API 密钥 · 请求日志 · 用量 · 浏览器 · 设置。

- 账号状态：**停用**＝CPA 里关了；**封号**＝额度接口回 403、凭证上有 ToS / 验证 / 授权失效信息、或这个号最近一次请求是 403；**冷却**＝CPA 标了 unavailable / error / 冷却中；其余**正常**。
- 自动停用（设置页两个开关，默认都开）：Google 回 403（ToS 封号 / 要验证账号 / 被停用）的号自动在 CPA 里停用，记下时间、原因和申诉 / 验证链接（存 `state.json`），账号页显示「自动停用 · 403 …」，仪表盘列出来。403 的来源：请求记录（这个号 24 小时内最近一次请求是 403）、额度接口的 403、CPA 凭证上的状态信息、探测。429 / 401 / 额度用完一律不算。探测＝经 CPA `/requests/api-call` 发一个 1 token 的生成请求（停用的凭证也能发），模型挑这个号自己有的最便宜的 Gemini Flash；一次只探一个号。自动停用的号每 30 分钟探一次，探通了才重新启用（「自动恢复」）；一小时没请求的闲置号也会偶尔探一下，没人用的封号也能抓到。**手动操作优先**：自己启用过的号清掉自动标记，之前的 403 记录不再算；自己停用的号永远不会被自动启用。
- 账号排序（点表头，再点反过来，记在浏览器里；卡片视图在全选旁边一排同样的按钮）：账号（邮箱）、状态（默认，封号 > 冷却 > 正常 > 停用）、等级、最近使用、5H / 7天剩余（各模型族取最少，重置时间已过算已恢复）、最早恢复；没数据的永远排最后，并列按邮箱。和搜索 / 筛选 / 全选 / shift 连选一起用，连选按显示顺序。
- CPA 自带的管理面板：设置页「CPA 面板」→ 新标签页打开 `cpa/`。
- 设置页每一项标题后有「?」，悬停或点开看说明，Esc 关。
- 改密码（设置页）：旧密码 + 新密码两遍（至少 8 位）。旧密码输错和登录共用限速。新密码的 scrypt 哈希存进 `state.json`，立即生效不用重启；除了当前这个，其余会话全部退出（浏览器页的连接一起断）。
- API 密钥（单独一页）：管 CPA 配置里客户端用的 `access.api-keys`，经 CPA 管理接口 `GET` / `PUT /v8/management/config/access/api-keys` 读写（带 `If-Match`，别处同时改了配置会重读再写，不会覆盖），CPA 立即生效不用重启。列表只显示前 6 位 + 后 4 位，点一下看全文，可复制；可以自己填（12–200 位，字母、数字和 `. _ ~ + / = -`）或一键生成（`sk-` + 40 位随机）；删除要确认。**最后一个删不掉**：CPA 一个密钥都没有时会关掉校验、谁都能用。备注（酒馆 / 手机之类）存在本面板的 `state.json`，按密钥的 sha256 记，不存明文；密钥没了备注跟着删。
- 模型档位（设置页）：读 CPA 的 `oauth.model-alias.antigravity` 和各账号的模型列表，每个模型的「默认 / low / medium / high」四个名字并排、可复制；没配别名的模型单独列出来。只读。

## 环境变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `APP_PASSWORD_HASH` | — | 初始登录密码的 scrypt 哈希，`npm run passwd -- '密码'` 生成（格式 `scrypt:盐:哈希`）。设置页改过密码以后以 `state.json` 里的为准，这个就不管用了 |
| `APP_PASSWORD` | — | 明文密码，只在没设哈希时用（本地调试） |
| `APP_PASSWORD_RESET` | 空 | `1`＝启动时丢掉设置页改的密码，回到上面 env 里的；用完删掉，不然每次重启都会丢 |
| `CPA_URL` | `http://127.0.0.1:8318` | CPA 地址 |
| `CPA_MANAGEMENT_KEY` | 必填 | CPA 管理密钥：`cpa/config.yaml` 里 `management.secret-key` 的明文 |
| `HOST` / `PORT` | `127.0.0.1` / `8321` | 监听地址 |
| `BASE_PATH` | 空 | 子路径，线上 `/me` |
| `DATA_DIR` | `./data` | 数据目录 |
| `USAGE_RETENTION_DAYS` | `30` | 请求记录保留几天 |
| `USAGE_POLL_MS` | `5000` | 多久取一次 CPA 用量队列 |
| `QUOTA_REFRESH_MINUTES` | `15` | 后台刷新额度间隔的默认值，0 关闭；设置页可改 |
| `QUOTA_CONCURRENCY` | `4` | 同时查几个号 |
| `AUTO_DISABLE_SWEEP_MS` / `AUTO_DISABLE_PROBE_SECONDS` / `AUTO_DISABLE_IDLE_SECONDS` | `30000` / `1800` / `3600` | 自动停用多久查一次（0 不查）/ 自动停用的号多久探一次 / 多久没请求算闲置。一般不用动 |
| `QUOTA_BASE_URLS` / `QUOTA_USER_AGENT` | Google 三个地址 / Antigravity UA | 一般不用动 |
| `COOKIE_SECURE` | 自动 | 自动＝请求经 https（`X-Forwarded-Proto`）才带 Secure；`1` / `0` 强制 |
| `TRUST_PROXY` | `1` | 信任 nginx 的 `X-Real-IP` / `X-Forwarded-*`（登录限速按 IP） |
| `SESSION_DAYS` | `30` | 登录有效期 |
| `BROWSERD_URL` / `BROWSERD_TOKEN` | `http://127.0.0.1:8331` / 空 | 本面板自己的 browserd；Token 为空就不显示浏览器页 |
| `BROWSER_UPSTREAM` | `http://127.0.0.1:3011` | Chromium 容器的 UI 端口 |
| `BROWSER_IDLE_MINUTES` | `30` | 没人看就关掉容器（省内存），0 不关 |

登录：一个密码，HttpOnly + SameSite=Lax 会话 Cookie；同一 IP 15 分钟内错 8 次（或全局 40 次）锁 15 分钟；所有写操作要带 `X-App-CSRF` 头。

## 本地预览

```sh
npm install
npm run dev      # 起 mock CPA（队列里预先放一周的假请求），打开 http://127.0.0.1:8321/me/ ，密码 agyme-dev
npm run check    # tsc
npm test
```

## 目录

```
src/      main（HTTP、静态文件、子路径）· api（接口）· auth（登录）· cpa（CPA 管理接口）· quota（额度抓取/缓存/后台刷新）
          accounts（状态分类、仪表盘统计）· autodisable（403 自动停用 / 探测 / 恢复）· usage（取 CPA 用量队列、请求记录库）· tiers（模型档位）· browser（远程浏览器代理）
          keys（API 密钥）· accerr（错误文字、申诉链接）· store（JSON 存储）· zip · util · passwd（生成密码哈希）
public/   index.html · app.js · filter.js（账号筛选/勾选逻辑）· app.css · theme.js · icons/
test/     mock-cpa.ts · fixture-usage.ts（用量队列记录）· dev.ts（npm run dev）· *.test.ts
ops/      browserd.py（多实例可配）· browserd.env.example · agy-me-browserd.service
deploy/   docker-compose.yml（CPA + agy-me）· cpa-config.example.yaml · agy-me.env.example
ref/      tools-ui-server.py（额度逻辑的出处）
```
