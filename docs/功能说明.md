# agy-me 功能与运维说明

## 页面与架构

仪表盘 · 我的凭证 · AI Studio · API 密钥 · 请求日志 · 用量统计 · 内置 Chrome · 设置。

### 1. 多后端统一网关（`/v1`、`/v1beta` 与 `/ais2/v1`）
- **主入口切换（CPA ↔ Antigravity-Manager）**：仪表盘和设置页提供 `CPA / AGM` 切换胶囊。所有未单独绑定的客户端密钥都会随全局设置实时切往对应后端，客户端无需改 URL 或换 Key。
- **按密钥独立路由**：在「API 密钥」页可为某一把 Key 单独指定 `跟随全局 / 固定 CPA / 固定 AGM / 固定 AI Studio`。密钥镜像同步在 `DATA_DIR/client-keys.json`（`0600`，`state.json` 不存明文密钥），就算 CPA 停机也可由本地继续完成鉴权、增删与转发到其他后端。
- **AI Studio 并存直达**：既可通过专属路径 `/ais2/v1` 调用，也可直接在统一主入口 `/v1` 中把模型名写成 `ais2/<模型名>`（例如 `ais2/gemini-4-argon-high`），网关会自动剥离 `ais2/` 前缀并将思考档位映射为上游参数。
- **隔离原生面板**：在设置页点击「打开」可通过 `/cpa/` 和 `/agm/` 打开两大后端的原版后台。服务端自动完成鉴权与管理密码注入，浏览器只持有会话 Cookie，真实管理密钥不落浏览器。

### 2. 凭证与账号管理
- **CPA 凭证页**：支持 OAuth、Refresh Token、JSON/ZIP 导入导出，四族额度圆环、按剩余额度自动排除模型、403/401 自动停用与探测恢复、闲置自动休眠。
- **CPA ↔ AGM 一键互导**：当同时启用 CPA 和 Antigravity-Manager 时，凭证页支持「同步到 AGM」与「从 AGM 导入」，直接通过 OAuth `email + refresh_token` 无损双向对齐。
- **AI Studio 纯自用页**：无分流、无代理池，支持上传 Cookie JSON/文本、精简模型开关、手动勾选暴露模型、单号存活检测与每日 16:00 重置配额估算。支持 `AISTUDIO2_MODE=exclusive`（默认单机独占自动认领）与 `shared`（多套面板共用同一后端时严格防互删）。

### 3. 统一请求日志与用量统计
- `DATA_DIR/usage.sqlite` 统一汇总三类后端流量（CPA 来自队列消费，AGM 与 AI Studio 来自网关实时流式 SSE 用量嗅探），每条记录均带 `backend` 标记（`cpa` / `agm` / `ais2`），支持在请求日志页按后端精确筛选。

## 老用户平滑升级与 Nginx 反代要点

1. **原位升级**：在服务器上直接重跑一键脚本：
   ```sh
   curl -fsSL https://raw.githubusercontent.com/xzhouzhou758/agy-me/main/deploy.sh | bash -s -- --upgrade
   ```
   会自动把旧容器内存限制从 `128m` 调整为 `256m`，挂载 `./cpa/catalog` 并在保持 `cpa/config.yaml` inode 不变的前提下补全 `send-keepalive-before-ft: true`。
2. **增配新后端**：重跑不加参数的 `deploy.sh` 选 `2`，即可在不重输密码、不覆盖原有 CPA 的情况下直接加装 `agm` 或 `aistudio2` 容器。
3. **前置反代调整（如果你之前用 Nginx 分别转发 `/me/v1 -> 8318` 和 `/me/ -> 8321`）**：
   为了让客户端统一走 `agy-me` 网关享受后端切换和防缓冲流式输出，只需把 `/me/` 全部转给 `127.0.0.1:8321` 即可：
   ```nginx
   location ^~ /me/ {
       proxy_pass http://127.0.0.1:8321;
       proxy_http_version 1.1;
       proxy_set_header Host $host;
       proxy_set_header X-Real-IP $remote_addr;
       proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
       proxy_set_header X-Forwarded-Proto $scheme;
       proxy_set_header Upgrade $http_upgrade;
       proxy_set_header Connection $http_connection;
       proxy_connect_timeout 60s;
       proxy_send_timeout 1300s;
       proxy_read_timeout 1300s;
       proxy_buffering off;
       proxy_request_buffering off;
       client_max_body_size 50m;
   }
   ```
